# ESP32 실링팬 조명·회전방향 제어

> 프로젝트 기록 · 2026-11-06 기준 / **검증 필요**  
> 이 폴더는 프로필 저장소에 남기는 **프로젝트 진행 기록**입니다. 전용 펌웨어 저장소나 검증된 동작 코드가 아닙니다.

## 목표

조명 일체형 천장 실링팬의 **겨울철 팬 회전 방향 변경**을 우선 구현하고, 이후 팬 전원·속도 및 조명 ON/OFF, Wi-Fi 제어로 확장할 계획입니다.

대상 실링팬과 리모컨의 **제조사/모델 및 통신 방식(IR/RF/BLE)** 은 아직 확인되지 않았습니다. 38kHz 적외선 수신기(VS1838B)만으로 무선 RF 리모컨을 분석할 수는 없습니다.

## 하드웨어 (사용자 조립 완료 보고)

- 기존 일반 ESP32-WROOM-32 개발보드 (ESP32-S3가 아님)
- VS1838B 38kHz IR 수신기: VCC→3V3, GND→GND, OUT→**GPIO27**
- VLT-PTS002 5mm 940nm IR 송신 LED: **GPIO25 → 220Ω 직렬 저항 → LED 애노드(+), LED 캐소드(−) → GND**
- USB 전원, 공통 GND; 리튬폴리머 배터리 및 별도 MOSFET 미사용

위 배선은 **계획/사용자 조립 보고**입니다. 실제 핀 배열·극성·전원·전압 파형은 별도 계측으로 검증해야 합니다.

## 지금까지 확인한 사항

| 항목 | 상태 | 근거 및 한계 |
| --- | --- | --- |
| 브레드보드 회로 조립 | 사용자 보고 | 외부에서 배선 실물 직접 검증하지 않음 |
| 로컬 에이전트의 송신 함수 실행 | 보고됨 | 시리얼 송신 시작·종료 로그 확인 |
| IR 루프백 | 미성공 | 마주 보는 송신 LED/VS1838B, 최초 5회 + 변경 펌웨어 5회 모두 수신 이벤트 **0건** |
| GPIO27 입력 | HIGH 관측 | VS1838B 대기 상태에서 HIGH는 가능하며 정상 수신의 증거는 아님 |
| 38kHz 변조/IR LED 발광 | 미검증 | 송신 함수 로그만으로 물리적 출력은 확정 불가 |
| VS1838B 수신 단독 | 미검증 | 외부의 정상 IR 리모컨 대조 테스트 필요 |
| 실링팬 통신 방식 및 제어 | 미검증 | 실링팬이 RF/BLE 방식일 수 있음 |

## 다음 테스트 순서

1. 실링팬 및 리모컨 모델을 식별해 통신 방식(IR/RF 등) 확인.
2. ESP32 GPIO25 송신 기능을 중지하고, **VS1838B GPIO27 수신 단독 테스트**부터 수행. 정상 동작하는 일반 IR 리모컨을 대조군으로 사용하여 버튼 수신 5회를 측정한다.
3. PC 테스트 프로그램에서 사용자가 리모컨 버튼을 누르면 자동 캡처하고 **Enter를 누를 때 회차 결과 저장**. 프로토콜, HEX, RAW 타이밍, LOW 에지, 오버플로 등을 기록한다.
4. IR 수신 정상 여부를 확인한 다음 GPIO25 LED의 물리적 발광 및 변조 신호를 별도로 검증. 같은 ESP32에서 송수신 타이밍 충돌 가능성도 확인.
5. 실링팬 리모컨이 IR 방식일 경우에만 해당 버튼 신호를 분석한다. 실제 회전 방향 변경은 **제조사 정지 절차를 확인한 후** 실시한다.
